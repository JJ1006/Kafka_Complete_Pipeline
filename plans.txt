Task 2.4 — Initialize & Unseal Vault
--------------------------------------------------------------------------------

  kubectl port-forward -n security svc/vault 8200:8200 &
  export VAULT_ADDR='http://127.0.0.1:8200'

  # Initialize — SAVE THIS OUTPUT SECURELY
  vault operator init -key-shares=5 -key-threshold=3 > vault-keys.txt

  # Unseal with 3 of the 5 keys
  vault operator unseal    # key 1
  vault operator unseal    # key 2
  vault operator unseal    # key 3

  vault login              # use root token from vault-keys.txt

  vault secrets enable -path=secret kv-v2
  vault auth enable kubernetes

  # Store application secrets
  vault kv put secret/credit-api \
    app_secret_key=$(openssl rand -hex 32) \
    jwt_secret_key=$(openssl rand -hex 32) \
    api_key=$(openssl rand -hex 24)

  vault kv get secret/credit-api    # verify

SECURITY: vault-keys.txt is in .gitignore. NEVER commit it. Store unseal keys
in a password manager. In real production use Vault auto-unseal with KMS.

Git Workflow
--------------------------------------------------------------------------------

Branch naming:
  feat/phase-1-scaffold
  feat/phase-4-ingest-endpoint
  fix/kafka-producer-retry
  chore/update-dependencies
  hotfix/auth-bypass-critical

Standard flow for each task:
  git checkout -b feat/phase-X-task-description
  # ... do the work ...
  git add .
  git commit -m "feat(scope): what was done"
  git push origin feat/phase-X-task-description
  gh pr create --fill
  # Review CI, fix any failures
  gh pr merge --squash

Commit message convention (Conventional Commits):
  feat:     new feature or endpoint
  fix:      bug fix
  test:     adding or fixing tests
  chore:    infrastructure, config, dependencies
  docs:     documentation
  refactor: code restructure, no behavior change
  perf:     performance improvement
  ci:       CI/CD changes

Examples:
  feat(auth): add JWT refresh token endpoint
  fix(dedup): handle Redis timeout gracefully
  test(integration): add DLQ routing test scenario
  chore(helm): pin Kafka chart version to 26.4.1
  docs(runbook): add Vault unseal procedure
  perf(cache): switch from json.dumps to orjson
